## Implemented corrections

- Cohesive desktop household workspace: active navigation, saved-request summary cards, current workflow stage, prominent recommended allocation and next action, and policy evidence beside the decision. Totals derive from saved request items, legs, fees, references and states. No environmental, collection or AI-success metrics were invented.
- Single comparison view before review; approved and declined requests show their own useful next steps instead of repeating the comparison. Both rejected-request badges remain Declined. Explicit acknowledgement and required data-wipe confirmation still gate approval; approval does not submit a booking.
- Aligned responsive comparison cards, readable fee amounts, consistent typography, spacing, surfaces, badges, action hierarchy and keyboard focus. Status pills are not buttons. Form widths remain bounded; desktop content has a balanced maximum width.
- Required field labels, native and inline validation, quantity/total-row-weight clarification, understandable loading/empty/error/disabled states. Fee lookup errors no longer appear as a zero/free fee; submitting is blocked while the fee is loading or unavailable.
- Evidence panel distinguishes current configuration, each stored extraction's provider/model, successful AI extraction, DOM fallback, fixtures, cache, stale evidence and failure. Retrieval timestamps are retained. Useful failure summaries stay visible; safe technical diagnostics and quotes expand separately. Historical Gemini errors remain intact. Failed generic-ai is never presented as success.
- Shared truthful confirmation view across all three portals: unknown/missing references cannot invent success, fees/items/weights come from the actual saved record, requested and dispatcher-assigned slots remain separate.
- All three portal navigations, public policy/rate pages, forms, confirmations, tracking and operator screens share improved spacing, wrapping, contrast, forms and controls while retaining their established green/amber/dark-orange identities.
- Deccan's mobile sidebar no longer compresses content into an unusably narrow column. PaperPlus and QuickScrap page overflow corrected. Operator tables scroll inside an accessible keyboard-focusable table region rather than overflowing the page. Operator test switches and reset controls are secondary expandable sections.
- Fixed operator repeated-fetch loop, duplicate pending-action clicks, unavailable-service/authentication distinction, measured-weight validation, and token submission via headers. Existing ownership, source validation, CAPTCHA handoff, approval hashes, evidence expiry, duplicate prevention and verification paths remain in place.
- Per user decision, QuickScrap public copy and current DOM fallback quote now agree with its existing ₹50 engine. The fee engine was unchanged. Historical repository fixture/test prices were retained and are clearly labelled fixtures; they must not be confused with current live pricing.
